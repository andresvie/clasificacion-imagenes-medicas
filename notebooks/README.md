# Notebooks

Esta carpeta contiene los Jupyter notebooks del proyecto.

## Notebooks disponibles

| Notebook | Descripción |
|----------|-------------|
| `01_exploratory_analysis.ipynb` | Análisis exploratorio de datos |
| `02_preprocessing.ipynb` | Pipeline de preprocesamiento |
| `03_feature_extraction.ipynb` | Extracción de características |
| `04_classification.ipynb` | Entrenamiento y evaluación de modelos |

## Ejecución

```bash
# Iniciar Jupyter
jupyter notebook

# O usar JupyterLab
jupyter lab
```

## Notas

Los notebooks utilizan los módulos en `src/` para mantener el código organizado y reutilizable.
